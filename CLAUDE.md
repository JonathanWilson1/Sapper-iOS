# Sapper-iOS

Falling-sand WW1 bunker survival game. **Read `.claude/skills/sapper/SKILL.md` first.** It covers the game rules, code map, publish and test commands, Jonathan's feedback history and the backlog.

- Game: `web/index.html` (single file). Publish with `scripts/deploy.sh` after committing to `main`.
- Tests: `tests/` (`npm i && npm run smoke`); outputs go to `/tmp/sapper-out/`.
- Live: https://jonathanwilson1.github.io/Sapper-iOS/
- A fun project with friends, not a revenue project.
